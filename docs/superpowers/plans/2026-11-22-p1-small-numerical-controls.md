5. A small observed error, repeated run or convenient high-energy cell subset must not silently become a qualified domain, deadband or successful diagnosis.

## Fixed recipe for review

### Conventions

Rate `F=44100`; normal control length `N=6912` samples (12 granules). `n` is an integer in `[0,N)`. All real formulas use Python binary64 `math.sin`, `math.exp`, `math.pi`; scalar expression order is preserved in code and recorded with Python/platform/library versions. Persist generated little-endian int16 bytes and SHA-256: these exact bytes, not a promise of cross-platform transcendental equality, are the run inputs.

Quantization is `q(x[n]) = int(round(x[n]))`, Python half-to-even. Check finiteness and the integer range before packing `<h`; never clip. There is no RNG, so no seed is needed. Exact zero signals are constructed with integer zeros. Duplicate generated byte sequences may share storage, but their recipe/role/variant rows must remain separately visible.

The diagnostic band-noise reference is `(1/12)*sum(w**2)` per natural FFT bin, summed through the existing partitions for all bins 0–512 including Nyquist and then mapped through existing bands. Reuse the three existing rounding-noise functions in `scripts/fl_studio/analyze_trial.py` through a research-only import, with no calls to that script's audio conversion or trial workflow. Hash that helper source and arrays. It assumes a declared noise model, not measured independent noise. Report energies relative to it continuously; adopt no 10/20/40 dB bins or qualification gate.

Compare per-source E/T and metadata over every captured call/band; report eligible bands 1–20 separately, with startup/ineligible cells retained in separate summaries. Use the existing loud/quiet tone pairs in both directions and exact-silence controls for the stored directional margin comparisons. Do not invent new paired captures where lengths differ.

Do not change independent values to make Python agree. Distinguish zero-reference absolute error from relative/log error, which is undefined at zero.

This provides reproduction evidence only for these already-captured signals. It does not independently validate the new controls below.

### Q — Fixed sustained and decay sensitivity controls

Sustained base pairs (10):

- `A[n] = 8192*sin(2*pi*1000*n/F)`.
- `B[n] = a*sin(2*pi*2000*n/F + phi)`.
- Cartesian product `a in {1,4,16,256,1024}`, `phi in {0,pi/2}`.

Decay base pairs (2):

- `A[n] = 0` for `n<2000`; otherwise `8192*exp(-((n-2000)/F)/tau)*sin(2*pi*1000*(n-2000)/F)`.
- `tau in {0.02,0.1}` seconds; phase resets at onset.
- `B[n] = 1024*sin(2*pi*2000*n/F)`.

For each of these 12 real-valued pairs, create exactly five representations:

| Variant | A counts | B counts |
| --- | --- | --- |
| nominal | q(A) | q(B) |
| A-plus | q(A+0.5) | q(B) |
| A-minus | q(A−0.5) | q(B) |
| B-plus | q(A) | q(B+0.5) |
| B-minus | q(A) | q(B−0.5) |

Offsets are applied once to the real waveform before integer rounding, not to already-quantized counts. Assert each changed channel differs by at most one count from nominal and the unchanged member's bytes are identical. This is a declared deterministic perturbation model, not a simulation of FL dither or an assertion that every actual export error has this pattern.

Analyze each representation in both directions: **12 pairs × 5 representations × 2 directions = 120 direction-cases**. Compare nominal and perturbed E_A, E_B, T_A, M, exact-silence and quiet-floor flags on identical geometric cell IDs. Report every finite delta, sign changes around zero and energy coordinates relative to the diagnostic reference. A sign change near zero is a finding, not automatically a software defect or perceptual change. No automatic cutoff fitting, bin search or cherry-picking stable cells.

### Z — Silent/quiet-floor transition checks

Base real pair: A is the 8192-amplitude 1 kHz sustained tone; B is the 1024-amplitude 2 kHz sustained tone, both phase zero. Five count pairs: nominal; A entirely zero; B entirely zero; nominal A with all samples `n>=3456` replaced by exact integer zero; nominal B with the same tail-zero operation. Analyze both directions: **10 direction-cases**.

Freeze a **diagnostic cell list C0** from nominal geometry plus the structural predicates (both windows nonzero, finite M, T>Q), solely to trace later values/flags. It is not S0: no energy regime or numerical allowance has been established. Preserve C0 after zeroing; retain finite raw M and all current flags, rather than dropping newly silent cells. Check that exact-silent maskers reach the existing quiet-floor control where predicted by the reviewed history, and that zero-target flags cannot be misread as healthy evidence merely because floored M is finite. Do not invent a settling-call count if the existing history/capture does not support it.

### B — Bounded near-zero boundary probe

This is a fixed numerical boundary search, not a diagnosis/policy parameter search:

- A is the 8192-amplitude 1 kHz phase-zero tone. B is a same-frequency tone with amplitude `a` and phase `phi in {0,pi/2}`; N remains 6912.
- Select one band by the maximum nominal A band energy among bands 1–20 at call 6; ties choose the smaller index. Record all band values and this deterministic choice. The selected band is not adopted as a musical region.
- For each phase, evaluate target amplitudes 1 and 32767. If M at call 6/selected band is not positive at the low endpoint and negative at the high endpoint, record `not_bracketed` and stop that phase. Do not broaden the search.
- Otherwise take integer midpoint `floor((lo+hi)/2)` for at most 15 iterations. A positive M replaces lo, a negative M replaces hi; exact zero, adjacent amplitudes or repeated midpoint stops. Keep the endpoint-sign invariant but make no global monotonicity claim about quantized spectra. Store every attempted amplitude, actual count hash and result. Never interpolate fractional-count audio or force a zero.
- Each attempted pair is analyzed in both directions with full-grid evidence. Maximum **2 phases × (2 endpoints + 15 midpoints) × 2 directions = 68 direction-cases**. Report nearest tested |M| and whether a bracket/adjacent endpoints were obtained; no claim that a desired closeness was achieved.

This gives boundary observations, not an independent-reference error bound. If the nearest cases do not constrain a future deadband, report the evidence gap rather than running an unregistered second search. Scalar margin-kernel tests with exactly constructed T/E can establish arithmetic/boundary semantics separately; they are not full-chain captures.
